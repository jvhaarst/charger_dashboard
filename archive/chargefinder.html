Two ways to skip the copy-paste

Userscript. In Tampermonkey, add a script that assigns window.cfLiveFetch = path => …GM_xmlhttpRequest…; requests from the extension carry no Origin, so the API answers. This page uses it automatically when present.

Relay. Any URL that fetches server-side and returns the body verbatim. Use {url} where the target goes, e.g. https://example.org/raw?url={url}, or give a plain base like http://localhost:8787/api and the path is appended. A public relay means a third party sees the requests.
